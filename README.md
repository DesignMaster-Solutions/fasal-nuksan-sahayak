# Fasal Nuksan Sahayak

Free, open-source helper for Indian farmers insured under the Pradhan Mantri Fasal Bima Yojana
(PMFBY): after hail, a landslide, waterlogging, a cloud burst, a lightning fire, or rain on a
harvested crop still drying in the field, it tells the farmer whether the loss must be reported by
the farmer, how many hours are left in the 72-hour window, the fastest way to report it (Krishi
Rakshak Helpline 14447, the Crop Insurance App, the insurer, the bank, the agriculture office),
what to have ready, and gives a ready-to-read report in Hindi or English.

Status: **not built yet.** This repository holds the scope (`BRIEF.md`) for an entry in the
Code for a Billion 2026 hackathon, track Agriculture. Every rule the tool will state is being
checked against the official PMFBY Operational Guidelines before it is coded; nothing here is
advice yet.

Planned: static web app (English and Hindi, under 100 KB, no account, no cookies), rule engine
with tests, anonymous public usage counter at `/stats`.
